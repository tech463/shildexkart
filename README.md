# ShieldX Ecommerce Admin

React + Vite conversion of the ShieldX ecommerce admin dashboard.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Chart.js + react-chartjs-2

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

Dev server: `http://localhost:5173`

## Structure

```
src/
  components/   Sidebar, Topbar, BackgroundEffects, Icons
  pages/        Dashboard, Vendors
  data/         Sample vendor data
  styles/       Premium glass theme CSS
```

The previous static HTML build is kept under `legacy/index.html`.
